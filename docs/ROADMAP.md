# Roadmap

Milestones are scope gates, not calendar promises.

| Milestone | Scope |
|---|---|
| 0.1 Foundation | App shell, design system, adaptive navigation, dashboard, registry, search, favorites, settings, local database, CI |
| 0.2 Developer | JSON, Base64/URL, hashes, UUID, timestamps, XML, regex and text diff |
| 0.3 Engineering | Ohm's law, resistor codes, LED helper, circuits and unit conversions |
| 0.4 Network | IP/CIDR, DNS, ping, TCP, HTTP, TLS and Wake-on-LAN |
| 0.5 System & Security | Device information, sensors, storage, password generator, file hashes and certificate inspection |
| 0.6 Server | Profiles, SSH host-key checks, monitoring API, Docker, uptime and Home Assistant |
| 0.7 Automation | Workflow model, visual builder, HTTP actions, conditions, webhooks, bounded schedules/retries, logs and cancellation |
| 0.8 Files & Productivity | File metadata/hash, CSV/JSON/XML, notes, tasks and import/export |
| 0.9 Scanner & 3D | QR/barcodes, filament and print cost, G-code inspection, printer profiles/integrations |
| 0.10 Diagnostics | Guided flows, network/server checks, log analyzer, error lookup, reports and history |
| 1.0 Stable | Regression, accessibility, performance and security review; documentation and signed Android release |

## Release gates

A milestone is releasable when:
- core flows work on the target Android versions
- validation and error states are implemented
- unit/widget/integration tests cover critical paths
- permission and privacy behavior is reviewed
- tablet and phone layouts are checked
- docs describe limitations and setup
